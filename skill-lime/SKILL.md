# 라임 버전 릴스

> 공통 규칙(계정 기준, 진행 순서, 검수, 총정리, 크레딧 절약)은 저장소 루트 `CLAUDE.md`를 따른다. 이 문서는 **디자인만** 다르다. Notion '릴스 레퍼런스' DB는 귀여운 버전과 공용이며, 행의 `스타일` 속성에 `라임`을 고른다.

## 쓰는 법
- 대본 JSON에 `"theme": "lime"`을 적으면 라임 스타일로 렌더된다(`src/lime/`). 귀여운 버전(`theme: cute`)은 그대로다.
- 컷 종류(kind)는 귀여운 버전과 같은 이름을 쓰고, 라임이 알아서 모양을 바꿔 그린다: text → 라벨·큰 제목 + 체크 행 / checklist·table·grid·compare → 라벨-값 행 / steps·flow·cards(2~3개) → 01·02·03 칸 / stat → 큰 숫자.
- 스티커, 말풍선, 이모지는 쓰지 않는다(이모지는 자동으로 지운다).
- 미리보기: `scripts/preview-cuts.sh <id> <대본> <프레임...>` 로 컷 이미지를 먼저 확인한다.

자세한 디자인 기준은 `references/content-design.md`.
