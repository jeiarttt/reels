# 라임 스타일 디자인 기준 (릴스용)

Figma 'runmate' 콘텐츠 템플릿(4:5 카드뉴스)을 우리 계정의 9:16 릴스에 맞게 옮긴 것이다. 레이아웃은 템플릿과 조금씩 달라도 된다(사용자 확정). 러닝 브랜드 고유 요소(로고, 러닝 사진, 영어 슬로건)는 쓰지 않는다.

## 색·글꼴
- 배경 `#141713`, 제목 `#FFFFFF`, 설명 `#C2C8BE`, 포인트(라임) `#E6FF65`, 별 `#E6FF63`, 정보 행 `#34362D`, 마지막 제목 `#F5F5EF`, 흐린 보조 `#6F756A`.
- 글꼴: **큰 제목(표지·본문 제목·마지막 제목)은 페이퍼로지 ExtraBold**(눈누 무료 폰트, SIL OFL 1.1, 상업·영상 사용 가능, 웹폰트 woff2 `public/fonts/Paperlogy-8ExtraBold.woff2`), 나머지(라벨·설명·카드 글자)는 Pretendard. 히피체는 쓰지 않는다. 라이선스 근거는 `fonts.md`.
- 글자 크기(px): 표지 제목 Bold 88 / 본문 제목 Bold 80 / 라벨 Bold 36(라임) / 설명 Regular 40 / 정보 행 36~44 / 마지막 제목 Bold 88. 행간 116~120%, 자간 -2.
- 글자 수 제한은 없다. 줄바꿈과 넘침만 렌더 후 확인한다.

## 화면(1080×1920)
- 배경: 모든 컷에 사진·영상을 깔고 그 위에 **위→아래 그라데이션 어두운 막**을 덮는다. 위는 연하게(`bgDim`×0.6), 글자가 있는 중간 높이는 `bgDim`(기본 0.5), 아래는 진하게(`bgDim`×1.3, 최대 0.85). 값은 대본 `bgDim`으로 조절한다. 배경이 없을 때만 단색.
- 표지: **화면 한가운데, 글자 가운데 정렬**. 상단 중앙 계정 글자, 큰 제목 2줄 + 설명 1줄, 별 2개.
- 본문(정보 컷): 어두운 단색 배경. 우상단 계정 글자, 라벨(라임) → 큰 제목 → 설명, 그 아래 내용 블록, 별 1개, 우하단 `01 / 05` 쪽 표시. 머리글과 내용을 한 덩어리로 세로 중앙(위 240~아래 380 안전 영역)에 둔다.
- 내용 블록: 정보 행(라벨-값, 높이 170, 둥근 30, 행 간격 28) 또는 01·02·03 칸(첫 칸만 라임) 또는 큰 숫자. **카드는 아이보리 `#F5F5EF`(어두운 글자 `#141713`, 라벨 어두운 올리브 `#4A5E00`, 보조 `#555B50`)** — 영상 위에서 정보가 잘 보이게 한다. 라임색은 배경 위 제목 강조·버튼·첫 칸에만 쓴다.
- 마지막: **화면 가운데, 글자 가운데 정렬**. 계정 글자 + 2줄 제목 + 라임 알약 라벨(책갈피 아이콘 + 문구, 영상이라 누르는 버튼이 아니므로 `↗` 같은 화살표는 쓰지 않는다), 장식 선·도형은 넣지 않는다(트랙·노선도 선 모두 뺐다 — 사용자 요청).

## 장식
- 장식 도형은 가로세로 1:1로 그린 SVG(`src/lime/parts.tsx`의 `Star`): burst(뾰족한 별)·sparkle(네 갈래 반짝이)·ring(동그라미 선)·plus·dots·moon. 컷마다 돌려 쓰고, 컷에 `shape`를 적으면 고를 수 있다. 한 컷에 1개(표지는 2개), 내용과 겹치지 않게. 비율을 늘리거나 찌그러뜨리지 않는다. 마지막 컷에는 선 모양 도형을 넣지 않는다. `Track`(노선도 선) 컴포넌트는 코드에 남아 있지만 쓰지 않는다(`src/lime/parts.tsx`). 내용과 겹치지 않게 놓고, 빈 곳을 채우려고 늘리지 않는다.
- 스티커, 말풍선, 일러스트, 이모지는 쓰지 않는다.

## 로고
- 계정 로고 파일이 없어 계정 글자(`brand`)를 라임색 글자로 쓴다. 로고 파일이 생기면 `Wordmark`만 교체한다.

## 사진·영상
- 표지, 본문, 마지막 모두 사용자가 준 영상·사진을 쓴다(AI 생성 안 함).
- 사진 안에 문구, 별, 로고를 넣지 않는다.

## 검수
1. 미리보기 이미지를 먼저 보고 확인받는다(새 스타일 첫 제작은 필수).
2. 렌더 후 컷마다 프레임을 뽑아 글자 넘침, 별과 내용 겹침을 확인한다.
3. 문구는 검수된 내용만 쓴다(공통 규칙).

## 영상 위 작은 글자 가독성 (2026-11-19 확정)
- 영상 위의 작은 글자(설명, 라벨, 계정 글자, 쪽 표시, 큰 숫자 설명)는 회색이 아니라 **흰색 Bold(700~800), 크기 38~42**로 쓰고 짙은 그림자(`textShadow`)를 깐다. 라벨·계정 글자는 라임색 Bold + 같은 그림자.
- 흰 카드 안 보조 글자는 어두운 회색 `#3F443B` Bold. 얇은 글자(Regular)는 영상 위에서 쓰지 않는다.
- 그래도 안 보이면 `bgDim`을 올린다(기본 0.5).

## 카드 없는 컷 종류 (2026-11-19 추가)
카드(아이보리 상자) 없이 영상 위에 바로 글자를 놓는 모양. 모두 흰색 Bold 글자 + 그림자 + 라임 포인트.
- `plain`: 큰 제목(+형광펜) 아래에 체크 줄(`chips` 또는 `cards[].big`). 조건 한두 줄일 때.
- `list`: 큰 라임 번호 01·02·03… + 글자 + 가는 구분선(`cards`). 기능·항목 3~5개 나열.
- `timeline`: 라임 선 위에 번호 동그라미가 이어지는 세로 절차(`cards` 2~4개). 입력 → 확인 → 알림 같은 순서.
- `split`: 왼쪽 큰 라임 숫자(`stat.big`, 숫자 세기 효과)·설명(`stat.sub`), 오른쪽 조건 줄(`cards`). 큰 숫자 하나 + 조건 2~4개.
- **원칙(사용자 확정)**: 컷을 전부 다르게 만들지 않는다. 기본은 카드형이고, **다르게 하는 편이 정보가 더 잘 전달되는 내용일 때만** 다른 모양을 쓴다. 기본 스타일(색·글꼴·그림자·기울임·형광펜·도형·배경 dim)은 어떤 모양이든 항상 똑같이 맞춘다.
- 내용에 따른 선택 기준: 핵심 숫자 하나가 전부면 `split`·큰 숫자 / 순서가 있는 절차면 `steps`·`timeline` / 같은 종류 항목을 나열하면 `list`·라벨-값 행 / 짧은 조건 한두 줄이면 `plain`이나 카드 행.
