# Notion 완료 처리 (Notion을 쓸 수 있을 때)

렌더까지 끝난 영상은 Notion '릴스 주제 후보'(collection://41b5ef70-1b68-817a-93dd-000b55e13fb1)의 해당 행에서 완료 처리하고, 행을 열면 대본과 관련 내용을 한 번에 볼 수 있게 본문을 채운다.

## 표(속성)와 본문의 역할
- **표(속성)에는 필터·정렬용 짧은 값만** 둔다: `주제`(제목), `상태`, `카테고리`, `시의성`, `사실확인`, `추천 구성`, `대표 출처`, `조사일`.
- **긴 글은 모두 행의 본문**에 둔다: 후킹 문구, 핵심 메시지, 시의성 근거, 조회수·트렌드 근거, 주의·출처 충돌, 대본, 캡션 등. (예전에 있던 `후킹 문구 안`, `핵심 메시지`, `시의성 근거`, `조회수·트렌드 근거`, `주의·출처 충돌` 칸은 본문으로 옮기고 표에서 삭제했다. 같은 칸을 다시 만들지 않는다.)
- 표 보기(Default view)는 `상태` 오름차순으로 정렬한다: 후보 → 선택 → 제작완료·보류 순이라 **제작이 끝난 행은 항상 맨 아래**로 간다.

## 속성 갱신 (완료 처리 때)
- `상태`: '제작완료' (영상을 만들지 않기로 했으면 '보류'와 그 이유를 본문 맨 위 "보류 이유"에 적는다)
- `사실확인`: 공식 출처를 직접 확인했는지에 맞게 갱신

## 새 후보 행의 본문 (후보를 조사해서 추가할 때)
중요도 순: 핵심 메시지 → 후킹 문구 안 → 주의·출처 충돌 → 시의성 근거 → 조회수·트렌드 근거. 조회수 지표를 못 찾으면 "직접 지표 없음"이라고 쓴다.

## 본문 구성 (완료 처리 후, 중요도 순)
상단 콜아웃: 제작 완료·검수 필요, 영상 파일 이름·규격, 영상이 Notion에 첨부됐는지 여부

1. 게시 전 확인할 것 (체크박스. 사람이 직접 확인할 항목)
2. 후킹과 핵심 메시지
3. 대본: 위에는 영상 문구를 순서대로 정리한 읽기 좋은 대본(`[첫 화면]`, `[1]`, `[2 · 카드]`, ... `[마지막]`, `[면책]`), 아래에는 대본 원본(script.json) 코드 블록. 같은 영상을 다시 렌더할 수 있는 정보만 담는다
4. 캡션과 해시태그
5. 영상에서 뺀 내용과 출처 주의 (공식 출처를 직접 확인했는지 포함)
6. 출처 (링크)
7. 시의성과 트렌드 근거
8. 장면 구성 (형식·길이·배경 사진 표)
9. 사용한 사진 (Pexels 링크와 ID)
10. 제작 검수 결과 (자동 검사 결과, 화면 검수, 약한 부분, 못 한 것)

대본은 표의 속성(칸)으로 만들지 않는다.

mp4는 Notion에 첨부할 수 있을 때만 첨부하고, 안 되면 본문에 "첨부되지 않음"이라고 적는다.
