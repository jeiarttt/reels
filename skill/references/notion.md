# Notion 완료 처리 (Notion을 쓸 수 있을 때)

렌더까지 끝난 영상은 Notion '릴스 주제 후보'(collection://41b5ef70-1b68-817a-93dd-000b55e13fb1)의 해당 행에서 완료 처리하고, 행을 열면 대본과 관련 내용을 한 번에 볼 수 있게 본문을 채운다.

## 속성 갱신
- `상태`: '제작완료' (영상을 만들지 않기로 했으면 '보류'와 이유)
- `후킹 문구 안`: 실제로 쓴 후킹 문구
- `주의·출처 충돌`: 제작일, 공식 출처 직접 확인 여부, 영상에서 뺀 내용, 게시 전 재확인 필요 항목 요약

## 본문 구성 (이 순서)
1. 상단 콜아웃: 제작 완료·검수 필요, 영상 파일 이름·규격, 영상이 Notion에 첨부됐는지 여부
2. 게시 전 확인할 것 (체크박스. 사람이 직접 확인할 항목)
3. 영상에서 일부러 뺀 내용과 이유
4. 장면별 문구 표 (순서, 형식, 문구, 배경 사진)
5. 캡션과 해시태그
6. 출처 (링크, 공식 출처를 직접 열어 확인했는지 표시)
7. 사용한 사진 (Pexels 링크와 ID)
8. 제작 검수 결과 (자동 검사 결과, 화면 검수, 약한 부분, 못 한 것)
9. 대본 원본(script.json) 코드 블록. 같은 영상을 다시 렌더할 수 있는 정보만 담는다

mp4는 Notion에 첨부할 수 있을 때만 첨부하고, 안 되면 본문에 "첨부되지 않음"이라고 적는다.
