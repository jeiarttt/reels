# 디자인 규칙 (폰트, 위치, 장면 형식, 글자 효과)

## 폰트 규칙
- **모든 장면의 큰 제목 문구(첫 화면 `hook`, 중간 장면 `text`, 마지막 화면 `cta`, 카드·표 장면의 제목 `text`)는 히피체**, **라벨·카드 안 숫자와 설명·표 셀·면책 문구 같은 작은 정보성 글은 Pretendard**로 쓴다.
- 히피체 제목은 자간 -1%(`letter-spacing: -0.01em`)를 적용한다. 히피체는 굵기가 하나(400)뿐이라, 굵게 보이도록 같은 색 외곽선(`-webkit-text-stroke: 0.035em currentColor`)을 얹는다. 제목 크기는 첫 화면 128px, 마지막 화면 112px, 중간 장면 94px(카드·표 제목 74px/72px). 크게 쓰는 대신 한 줄은 **공백 포함 12자 안팎**으로 짧게 나눈다(13자 이상이면 줄 끝 한두 글자가 아래로 떨어져 어색해진다). Pretendard는 400/700/800/900을 쓴다.
- 폰트 파일은 `public/fonts/`에 둔다.
  - 히피체: `hippie.woff2` — `@font-face { font-family: 'Hippie'; src: url('https://cdn.jsdelivr.net/gh/Project-Noonnu/2610081905@hippie/hippie/hippie_히피체.woff2') format('woff2'); font-weight: 400; }` 에서 받은 파일 (주소의 한글은 `%ED%9E%88%ED%94%BC%EC%B2%B4`로 인코딩해서 받는다)
  - Pretendard: npm `pretendard` 패키지의 `dist/web/static/woff2/Pretendard-{Regular,Bold,ExtraBold,Black}.woff2`
- 라이선스: 히피체는 SIL OFL 1.1(눈누 안내 기준 개인·상업 이용 무료, © AI올컷), Pretendard는 SIL OFL 1.1. 영상에 쓰는 것은 문제없지만 **폰트 파일을 저장소·배포물에 포함할 때는 저작권 고지와 라이선스를 함께 둔다**(`public/fonts/*-LICENSE.txt`). 폰트 파일 단독 판매·본인 제작처럼 재배포는 금지.
- 히피체는 글자가 넓어서, 한 줄이 길면(공백 포함 12자 초과) 화면 폭(약 920px)을 넘길 수 있으니 `\n`으로 나눈다.

## 표지(첫 화면)
- 첫 화면은 모든 장면의 **표지**다. 중간 장면과 다르게 만든다: 위쪽에 채널 태그(`brand`, 흰색 알약), 사진을 위쪽에 넓게 보여 주고, **제목은 아래쪽**에 가장 크게(128px) 둔다. 제목 아래에 포인트 컬러 강조 줄, 제목이 앉는 아래쪽에 어두운 그라데이션을 깔아 글자를 받친다. 맨 아래에 면책 문구.
- 표지 제목은 **3줄 이내, 줄당 12자 안팎**으로 쓴다. 이모지는 줄바꿈을 만들어 표지가 어색해지니 표지 제목에는 쓰지 않는다(캡션에서만).
- 표지 컴포넌트는 `src/components/CoverScene.tsx`.

## 세로 위치
- 모든 장면의 내용 블록은 화면 정중앙보다 **약 70px 위**에 둔다(하단 `padding-bottom: 140px`). 하단 면책 문구·플랫폼 UI와 겹치지 않게 하기 위해서다.

## 장면 유형 고르기
- **아래 유형(text, cards, table)은 기본 제공 예시일 뿐이며 꼭 이 둘만 쓰라는 뜻이 아니다.** 내용에 더 잘 맞는 형식(체크리스트, 단계 타임라인, 큰 숫자 하나 강조, 전후 비교, 순위, 말풍선, 달력·마감일 표시 등)이 있으면 자유롭게 쓴다. 기준은 **가독성**이다.
- 기본 유형에 없는 형식이 필요하면 `src/components/`에 새 장면 컴포넌트를 추가하고 `src/types.ts`의 `kind`와 `src/Reel.tsx`에 연결한다. 이때도 폰트 규칙, 단어 단위 줄바꿈, 과하지 않은 등장 효과, 세로 위치, 밝은 배경 위 글자 대비를 지킨다.
- 새 형식을 만들었으면 렌더 전에 정지 화면으로 글자 잘림·겹침·대비를 확인한다.
- 숫자·기간·금액 같은 핵심 수치가 3개 이상이면 `cards`로 보여준다.
- 연도·조건·제도를 나란히 비교하면 `table`로 보여준다. 값이 확정되지 않았으면 셀에 "미공고"처럼 쓴다.
- 나머지는 `text`. 영상 하나에 text만 이어붙이지 말고, 내용에 맞으면 cards 또는 table을 1~2장면 넣는다.
- 카드는 불투명한 흰색 배경에 큰 숫자는 포인트 컬러, 설명은 짙은 남색이다. 카드의 `big`은 짧게(한 줄, 10자 안팎), `small`은 설명 한 줄. 표 셀은 한 칸 2줄 이내(`\n` 가능).

## 여백 (정보성 내용: 카드·표)
- 카드·표는 **여백을 넉넉하게** 둔다. 좌우 바깥 여백 약 88px(표 76px), 카드 사이 간격 40px, 카드 안쪽 여백 46×52px, 표 셀 안쪽 여백 38×22px, 라벨과 내용 사이 48px, 제목과 카드·표 사이 60px 이상.
- 정보성 글자는 Pretendard: 카드 숫자 88px, 카드 설명 44px, 표 42px, 라벨 40px. 표 열이 2개면 비율을 0.85 : 1.4로 둔다.
- 오버레이는 사진을 살리는 쪽으로 낮게(첫 화면 0.28, 텍스트 장면 0.22, 카드·표 0.22). 주황 강조가 잎·물건 위에서 묻히면 오버레이를 조금 올린다.

## 텍스트 효과·줄바꿈 규칙
- 글자는 **단어 단위로 아래에서 살짝 올라오며 페이드인**한다(간격 약 0.1초, 이동 20px 안팎). 흔들림·회전·확대 같은 과한 효과는 쓰지 않는다.
- 카드는 하나씩 위로 떠오르듯, 표는 머리글 → 행 순서로 등장한다. 장면 끝에는 짧게 페이드아웃.
- 줄바꿈은 **단어(띄어쓰기) 단위**로만 한다. 한 단어를 글자 중간에서 끊지 않는다(`word-break: keep-all`). 조사가 붙은 덩어리("[[핵심 단어]]를")도 끊지 않는다.
- 의미 단위로 `\n`을 직접 넣어 한 줄 길이를 고르게 맞춘다(한 줄 12자 안팎).
