# 영상 뒤에 항상 만드는 "총정리" 페이지 (자동 DM·리틀리 링크용)

릴스를 올리면 자동 DM(리틀리 링크)으로 **관련 총정리**를 공유한다. 릴스에 다 못 담은 궁금증(신청 방법·조건·일정)을 한 페이지에 모은다. 영상 전달 때 커버·게시글 요약과 **함께 마지막에 항상** 만든다.

## 원칙
1. **범위**: 릴스에 나온 주제·항목만 다룬다. 릴스에 없던 다른 제도·상품은 넣지 않는다(예: 6가지 영상이면 그 6가지만). 항목마다 사람들이 궁금해 할 것(대상·조건·신청 방법·일정·준비물·유의점)을 채운다.
2. **사실만**: 영상과 같은 검수 기준. 공식 원문으로 확인한 것만 쓴다. 확인 못 한 항목은 비우지 말고 "아직 공개·확정되지 않았어요" 또는 "공식 사이트에서 확인해 주세요"라고 쓴다. 지어내지 않는다.
3. **기준일과 상태**: 맨 위에 기준일("2026년 11월 17일 기준")과 상태(시행 중 / 예산안·확정 전)를 쓴다. 확정 전 내용은 신청이 열리지 않았음을 분명히 쓴다.
4. **출처**: 맨 아래 공식 링크. 각 항목 옆에 어떤 출처인지 알 수 있게 한다.
5. **톤**: 영상과 같은 해요체, 상경러 입장의 한마디는 한 줄 이내. 보장·압박 표현 금지.

## 페이지 구성 (Notion, 해당 영상 행의 하위 페이지)
1. 제목: "📌 총정리 | <주제>"
2. 한눈에 보기: 핵심 3줄 + 기준일·상태
3. 항목별 안내(영상에 나온 순서): 대상·조건 / 신청·이용 방법(단계) / 일정 / 준비물 / 유의점
4. 자주 묻는 질문(Q&A 3~5개, 영상 주제 안에서)
5. 알아둘 점: 변경될 수 있는 것, 확인 못 한 것
6. 공식 링크 모음
7. 마지막 줄: 기준일과 "변경될 수 있어요"

## 공유 링크
- Notion 페이지를 만든 뒤 사용자가 **공유 → 웹에 게시**를 켜면 그 주소를 리틀리 자동 DM 링크로 쓸 수 있다(공개 설정은 사용자가 직접). 채팅에는 페이지 링크와 붙여 넣기용 요약을 준다.
- 영상 행(귀여운 버전 DB)에서 하위 페이지로 만들고, 행 본문 끝에 링크를 적는다.
