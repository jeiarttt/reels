# 귀여운 디자인 규칙

기본 스킬과 **폰트는 같다**: 큰 제목 히피체(자간 -1%), 작은 정보성 글 Pretendard. 폰트 파일과 라이선스는 `skill/references/design.md`·`skill/references/stock.md`의 폰트 부분을 따른다.
- **히피체로 쓰는 것**: 큰 제목, **라벨(알약), 표지 위 채널 태그, 마지막 화면 라벨, 의성어 태그**. 히피체는 글자가 작아 보여서 같은 자리의 Pretendard보다 크기를 4~8px 키운다(라벨 50px, 채널 태그 42px, 마지막 라벨 62px).
- **Pretendard로 쓰는 것**: 정보 내용 전부 — 카드의 숫자·설명, 표(체크 메모)의 칸 이름과 값, 면책 문구. 정보는 또렷하게 읽혀야 하므로 히피체를 쓰지 않는다.
- **글자에 외곽선(stroke)을 넣지 않는다.** (기본 버전에서 쓰던 `-webkit-text-stroke`는 귀여운 버전에서 뺐다.) 글자는 굵기를 억지로 키우지 말고, 파란 바·흰 말풍선·카드 위에 올려 대비로 읽히게 한다.

## 색 (채도 높은 파랑 + 읽기 좋은 대비)
| 이름 | 값 | 용도 |
|---|---|---|
| BLUE | `#2457F5` | 포인트. 흰 글자 위 대비 5.6:1, 흰 배경 위 파란 글자 5.6:1 |
| NAVY | `#13213F` | 본문 글자 |
| SKY | `#E6EEFF` | 연한 바탕(아이콘 원, 칩) |
- 포인트 색은 파랑 하나만 쓴다. 주황·초록 등 다른 포인트를 섞지 않는다.
- 파란 바 위에는 흰 글자, 흰 카드 위에는 NAVY 글자 + BLUE 숫자. 사진 위에 글자를 직접 얹지 않는다(바·말풍선·카드 위에만).

## 배경
- 기본 스킬의 사진 규칙(`skill/references/stock.md`)을 따른다(밝은 감성 라이프스타일 고해상도). 오버레이는 거의 없이(dim 0.04) 흰 베일 0.1로 파스텔 느낌을 준다.

## 장면 구성요소 (`src/cute/`)
| 요소 | 컴포넌트 | 쓸 때 |
|---|---|---|
| 표지 | `CuteCover` | 첫 화면. 채널 태그 + 라벨 + 파란 마커 띠 제목(132px) + 스티커 |
| 말풍선 | `CuteBubble` | 한 줄 메시지. 스티커가 있으면 말풍선 꼬리가 스티커를 향한다 |
| 이모지 카드 | `CuteCards` | 숫자·조건 3개. 아이콘 원 + 마스킹 테이프 + 살짝 기울임 |
| 체크 메모 | `CuteList` | 일정·절차(표). 위쪽 스파이럴 + ✅ 행 |
| 마지막 화면 | `CuteCta` | 저장 유도. 알약 버튼이 두근거리고 마커 띠 문구 |
- 레이아웃은 자유롭게 바꿔도 된다(새 컴포넌트 추가 가능). 단 가독성·여백·한 컷 하나의 메시지는 유지한다. **화면 상단 진행 점(인디케이터)은 쓰지 않는다**(사용자 요청).
- 마커 띠 제목: 강조 구간은 **한 덩어리의 흰 칩**, 조사·어미는 칩 밖. 강조는 영상 전체 3곳 이내.
- **영상 화면에는 면책 문구("변경될 수 있어요")를 넣지 않는다**(사용자 요청). 대신 **캡션 마지막 줄**에 "(○○년 ○월 기준 · 변경될 수 있어요)"를 반드시 쓴다. 검사기는 이를 확인한다(귀여운 테마는 캡션에 "기준"이 없으면 오류).

## 라벨 글자 중앙 정렬
- 모든 라벨·채널 태그·의성어 태그는 공용 `LabelBox`(`src/cute/parts.tsx`)를 쓴다: 줄 높이 1, 위아래 **대칭** 여백, 히피체 보정(`HIPPIE_SHIFT_EM = 0.05`).
- 라벨 도형의 높이를 바깥 상자에서 늘리지 않는다(늘어나면 글자가 위로 쏠린다). 위아래 여백을 눈대중으로 다르게 주지 않는다.
- 히피체는 글자 중심이 줄 상자 중심보다 약 0.05em 위에 있어 그만큼 내려 맞춘다. 폰트나 크기를 바꾸면 렌더 화면에서 글자 위·아래 여백을 픽셀로 재서 보정값을 다시 정한다(기울기가 있는 라벨은 기울기를 되돌려 측정).

## 움직임
- **라벨(알약)은 작게 튀어나오지 않는다.** 크기를 0에서 키우면 글자가 거칠게 깨져 보인다. 제자리에서 투명도 + 살짝 위로 올라오는 정도로만 등장시킨다(8프레임).
- **컷 전환은 짧게**: 배경 페이드 3프레임, 컷 끝 페이드 4프레임. 배경이 천천히 나타나는 동안 라벨·진행 점만 먼저 떠 보이지 않게 한다.
- 단어/카드가 통통 튀며 등장(spring), 스티커는 계속 살짝 흔들림. 흔들림 폭은 작게(과하지 않게). 컷 끝에 짧은 페이드아웃.

## 다이어리 꾸미기 컨셉 (현재 기본)
- 말풍선·카드·표는 **크림색 줄 노트 종이**(살짝 기울임) + **와시테이프 2조각** + **컷 번호 동그라미**로 만든다. 라벨은 **노란 포스트잇**, 강조는 **노란 형광펜**(파란 글자).
- 표지 브랜드는 점선 도장 모양, 제목 띠에는 테이프 조각을 붙인다. 구현은 `src/cute/parts.tsx`의 `Paper`·`Washi`·`NumTag`·`Pill`.
- 줄 노트 컷은 글자 줄 높이(114px)와 종이 줄 간격을 맞춘다(3줄까지).
- 이전(둥근 흰 말풍선) 모양으로 되돌리려면 이 변경 커밋의 직전 커밋으로 `src/cute`와 `src/components/Words.tsx`를 되돌린다.

## 사진 위 큰 글자 + 말풍선 + 낙서 컨셉 (현재 기본, 다이어리 컨셉 대체)
- 표지·글자 컷·마지막 화면은 종이 없이 **사진 위에 큰 흰 글자**(히피체, 부드러운 그림자, 외곽선 없음). 강조 구간만 **파란 칩 + 흰 글자**.
- 라벨은 **파란 말풍선(꼬리 달림)**, 분류·브랜드는 **어두운 남색 알약 태그**, 장식은 **흰 선 낙서**(반짝이·하트·물결·화살표, 그려지듯 등장).
- 읽기 쉽도록 배경 어둡게(dim 0.3)와 글자 뒤 부드러운 어두운 번짐을 쓴다. 카드(숫자) 컷만 흰 카드.
- 위치(2026-11-17 변경): 모든 컷의 내용 덩어리는 **세로 정중앙**(flex 중앙 정렬). 좌우 여백은 120~130px(제목·카드 폭을 줄여 확보). 이전의 "중앙보다 조금 위" 규칙은 사용자 요청으로 폐지.
- 영상 전체 길이 25초(표지 2.8 + 컷 3~3.8 + 마지막 2.6).
- 이전 다이어리(줄 노트·테이프) 모양은 커밋 `ade9556`에 있다. (참고 이미지의 문구·구성은 따라 하지 않고 느낌만 쓴다.)

## 배경 사진 고르기 (사용자 요청: 매번)
- 영상마다 배경은 **주제와 어울리는, 심플하고 밝은 사진**으로 새로 고른다(Pexels). 사람 얼굴·로고·복잡한 장면은 피한다. 같은 사진은 영상 안에서 2번까지만.
- 밝은 사진이면 대본에 `bgDim`(예: 0.14)으로 어둡기를 낮춘다(기본 0.3).
- **글자 대비**: 채도 높은 파랑·청록 배경은 흰 글자, 흰색·연회색 같은 옅은 배경은 해당 컷에 `"tone": "dark"`(진한 남색 글자·파란 강조·파란 낙서)를 쓴다. 렌더 후 컷마다 글자가 읽히는지 화면으로 확인한다.
- 주제와 연결 예: 결제·교통 → 카드를 대는 장면, 하늘과 가로등, 흰 배경의 스마트폰 / 혜택·예산 → 맑은 하늘·깔끔한 책상.

## 컷 레이아웃 고르기 (사용자 요청: 내용에 맞게 다양하게)
글자 컷과 카드만 반복하지 않는다. **내용의 성격에 맞는 형식**을 컷마다 고르고, 연속 두 컷에 같은 형식을 쓰지 않는다.
| 내용 성격 | kind | 데이터 |
|---|---|---|
| 한두 문장 설명·주의 | `text` | `text` (2~3줄) |
| 숫자·항목 2~4개 나열 | `cards` | `cards[]` (big/small/emoji) |
| 방법·절차(순서 있음) | `steps` | `cards[]` 2~4개 → 번호 동그라미 + 점선으로 이어지는 세로 타임라인 |
| 핵심 숫자·날짜·나이 하나 | `stat` | `stat{big, sub, emoji, gauge?}` → 큰 원 안에 숫자. 비율이면 `gauge`(0~100)로 고리 게이지 |
| 되는 것 / 안 되는 것 | `compare` | `compare{leftTitle, leftItems[], rightTitle, rightItems[]}` → ✅/❌ 두 칸 |
| 항목 4~6개 한눈에 | `grid` | `cards[]` 4~6개 → 2열 타일 |
| 기간·일정 | `table` | `table{head, rows}` → 체크 메모 |
- `stat`의 `big`은 짧게(3자 이하가 가장 크게 나온다, 6자 이하). `compare`는 항목당 한 줄 안에 들어오게 쓴다.
- 새 형식도 밝은 배경이면 `tone: "dark"`로 낙서 색을 맞춘다.

## 글자 넘침 확인 (매 영상, 렌더 후)
- 컷마다 **글자가 다 나온 프레임**을 영상에서 뽑아(`ffmpeg -ss <시각>`; 정지 이미지 명령은 최신 props가 필요) 박스·원·가장자리를 넘거나 잘리는 글자가 없는지 본다.
- 원 안 글자는 3줄을 넘기지 않는다. 조건이 길면 `stat.chips`로 원 밖 알약에 둔다. 항목이 5개 이상이거나 칸 폭이 좁으면 `compare.stack: true`로 위아래로 쌓아 글자를 키운다.
- 일러스트(`deco`)는 위쪽 모서리(`tl`/`tr`, 위에서 230px)에 둬서 라벨·본문과 겹치지 않게 한다.

## 스티커·일러스트 개수 (사용자 요청)
- 스티커(`sticker`, `hookSticker`, `ctaSticker`)와 일러스트(`deco`, `hookDeco`, `ctaDeco`)를 **합쳐서 영상 하나에 1~3개**. 컷마다 붙이지 않고, 강조가 필요한 곳과 주제가 잘 드러나는 곳만. 검사기가 3개 초과를 경고한다.
