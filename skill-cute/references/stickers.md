# 스티커

## 쓰는 원칙
- **마구 붙이지 않는다. 필요하거나 강조할 곳에만.** 영상 전체 최대 3개: ① 표지(첫인상) ② 놓치면 안 되는 컷(마감·주의) ③ 마지막 화면. 일반 설명 컷에는 붙이지 않는다.
- 같은 스티커 반복 금지. 표정이 내용과 어울려야 한다(아래 표).
- 스티커가 가리는 글자가 없게 둔다. 스티커가 있는 말풍선만 꼬리가 스티커를 가리킨다.
- 이모지는 일반 유니코드 이모지만 쓴다. 특정 캐릭터·유료 이모티콘을 모방하거나 복제하지 않는다.

## 모양대로 오린(다이컷) 사진 스티커
- 동그랗게 자르지 않고 **피사체 윤곽을 따라 오리고 흰 테두리**를 두른다(PNG, 투명 배경, `public/stickers/`).
- 소재: 동물의 엽기 귀여운 표정, 자취 소품(컵라면 등). **사람 얼굴·브랜드 로고·상호가 보이는 사진은 쓰지 않는다.**
- 출처: Pexels 등 상업 이용 가능 사진. 사진 ID를 기록한다(아래 표).

### 만드는 법
```bash
python3 scripts/make-sticker.py <사진.jpg> public/stickers/<이름>.png <x,y,w,h>
```
`x,y,w,h`는 피사체를 감싸는 사각형(0~1 비율). 배경이 피사체와 구분될수록 잘 오려진다. 만든 뒤 반드시 눈으로 확인하고(잘린 부분, 남은 배경), 이상하면 사각형을 조정하거나 다른 사진을 쓴다. (필요: `pip install opencv-python-headless numpy pillow`)
