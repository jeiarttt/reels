# 제작 직전 최종 검수 (렌더 전 필수)

영상을 만들기 **직전에**, 대본의 내용이 사실인지 마지막으로 검수한다. 검수 결과는 채팅에 표로 보여 주고, 하나라도 "수정 필요"면 고친 뒤 다시 검수한다. 통과한 뒤에만 렌더한다.

## 1. 사실 검수 (가장 중요)
- 영상에 나오는 **모든 수치·날짜·조건·대상·절차**를 하나씩 뽑아, **공식 기관 자료**로 다시 확인한다. 이전에 확인했더라도 제작 당일 다시 한다.
- 공식 기관 도메인으로 한정해 검색한다: `korea.kr`(정책브리핑), `fsc.go.kr`(금융위원회), `kinfa.or.kr`(서민금융진흥원), `gov.kr`, 각 부처 사이트. 주제에 맞는 기관을 추가한다. 언론·블로그만 있는 항목은 "공식 미확인"이다.
- 대조표를 만든다: `영상 문구 | 공식 자료의 근거 문장(출처 URL) | 판정(일치/수정 필요/확인 불가)`.
- **확인 불가·불일치 항목은 영상에서 뺀다.** 출처마다 값이 다르거나(예: 회차별로 바뀌는 소득 기준, 비율) 개념이 헷갈리면(금리 vs 정부 기여금) 넣지 않는다.
- 공식 페이지 원문을 직접 열지 못한 경우(네트워크 제한)에는 그 사실을 `verify_before_post`와 Notion에 **그대로** 적는다("검색 결과 기준, 원문 직접 열람 못 함"). 열람한 것처럼 쓰지 않는다.

## 2. 문구 검수
- **강도**: 근거가 "~할 수 있다"이면 영상도 "~할 수도"로 쓴다. 근거보다 단정적으로 쓰지 않는다(예: "달라질 수 있다" → "달라져요" 금지).
- **자격·대상 한정**: 특정 조건을 충족한 사람에게만 해당하는 내용이면, 그 한정이 컷에 있어야 한다. 한정 없이 행동을 권하는 문구("지금 가입하세요", "개설하세요")는 쓰지 않는다. 한정이 컷에 들어갈 자리가 없으면 행동 권유를 "확인하세요"로 바꾼다.
- **시점**: 오늘 날짜 기준으로 마감·종료가 지나지 않았는지, 이미 끝난 단계(신청 마감 등)를 현재 가능한 것처럼 말하지 않는지 확인한다.
- **후킹 ↔ 본문**: 표지가 약속한 날짜·수치가 본문에 있고, 표지만 보고 오해할 여지가 없는지 확인한다.
- **금지 표현**: 보장·압박("무조건", "100%", "안 하면 손해")이 없는지.

## 3. 캡션·검수 목록
- 컷에서 줄인 중요한 정보(절차 순서, 예외 조건)는 캡션에 있고, 캡션 내용도 공식 자료와 일치하는지 확인한다.
- `sources`는 공식 기관 링크를 우선으로 쓴다. `verify_before_post`에는 확인한 것, 확인하지 못한 것, 뺀 것, 고친 것을 모두 적는다.

## 4. 순서
1. 대본 초안 → 2. **최종 검수(위 1~3) 표를 채팅에 공개** → 3. 수정 → 4. `npm run validate` → 5. 정지 화면 확인 → 6. 렌더 → 7. 화면 검수 → 8. Notion 완료 처리(사실확인 등급을 검수 결과에 맞게 갱신: 공식 자료로 확인 = "공식 출처 있음", 언론만 = "출처 교차 확인", 불확실 = "공식 확인 필요")
